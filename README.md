# Aether BI — Generative Business Intelligence Assistant

Aether BI is a premium AI-powered Business Intelligence platform that converts natural language questions into SQL queries, visual analytics, KPI dashboards, and AI-generated business insights.

Built using Flask, SQLite, Plotly, Tailwind CSS, and Local LLMs (Ollama + Llama 3.2).

---

# Features

## AI Natural Language to SQL
Ask questions like:

- "Show total sales by region"
- "Which product has highest revenue?"
- "Forecast next month sales"

The AI automatically:
- Understands the question
- Generates SQL queries
- Executes SQLite queries
- Creates visualizations
- Generates business insights
